# 波長板・楕円偏光 3D シミュレーション

直線偏光が **偏光板 → 波長板（位相差板）→ 楕円偏光** と変化する様子を、実空間で
デフォルメして動的に3D表示する教育用 Web アプリです。

- **左奥**: 回転する円盤状の偏光板（黄色いバー＝透過軸）
- **緑の波**: 偏光板を出た直線偏光（電場ベクトルの束＝櫛付き）
- **中央の直方体**: 波長板。入口で **進相軸(シアン)・遅相軸(オレンジ)** の2成分に分解
- **板の中**: 遅相軸成分だけ位相が遅れ、出口で位相差 δ がつく
- **右手前**: 2成分が合成されて **楕円偏光** に。スクリーン上で電場ベクトルが回る

姉妹アプリ [`../PoincareSphere`](../PoincareSphere/) が抽象的なポアンカレ球で偏光変換を
表すのに対し、本アプリは実空間で波の伝搬そのものを見せます。

## 起動方法

```bash
# 組み込みサーバーで起動（デフォルト: ポート3000）
node server.js

# ポート指定
PORT=8080 node server.js

# npm scripts
npm start
```

ブラウザで `http://localhost:3000/` を開いてください。
Three.js を CDN から読み込むため、**実行時にインターネット接続が必要**です。

## 操作方法

| 操作 | 説明 |
|------|------|
| **偏光板 角度 φ** | 入射直線偏光の向きを変える（進相軸からの角度）。分解比 Ef:Es が変化 |
| **波長板 δ**（λ/4・λ/2・λ ボタン / スライダー） | 位相差を切替。出力が 円 / 直線 / 楕円 に変わる |
| **再生 / 一時停止** | 波のアニメーションを止めてじっくり観察 |
| **速度** | アニメーション速度（0〜3倍） |
| **波長** | 波の色を変える（380〜750nm の可視光近似色） |
| **ドラッグ** | 3Dビューを回転 |
| **ホイール** | ズーム |

## 見どころ（プリセット）

| 偏光板 φ | 波長板 δ | 出てくる光 |
|---------|---------|-----------|
| 45° | λ/4 板 | **円偏光**（電場ベクトルが円を描いて回る） |
| 45° | λ/2 板 | **直線偏光**（向きが 90° 回転） |
| 45° | λ 板 | **直線偏光**（入射とまったく同じ） |
| 20° など | λ/4 板 | **楕円偏光**（つぶれた円） |

> 表示は説明用にデフォルメしています（波長・板厚・旋光方向は実スケール・厳密規約ではありません）。
