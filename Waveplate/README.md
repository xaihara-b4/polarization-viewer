# 波長板・楕円偏光 3D シミュレーション

直線偏光が **偏光板 → 波長板（位相差板）→ 楕円偏光** と変化する様子を、実空間で
デフォルメして動的に3D表示する教育用 Web アプリです。

- **左上（奥）**: 回転する円盤状の偏光板（黄色いバー＝透過軸）。ここから光が出射する
- **緑の波**: 偏光板を出た直線偏光（電場ベクトルの束＝櫛付き）
- **中央の直方体**: 波長板。入口で **進相軸(シアン)・遅相軸(オレンジ)** の2成分に分解。
  入口面・出口面には成分と合成の矢印が伸縮表示され、**入口では2成分が同位相（＝直線）、
  出口では遅相軸が δ だけ遅れて合成が楕円を描く**ことを見比べられます。
  出口面では各成分の先端から合成の先端へ破線が引かれ、**合成＝進相＋遅相**（平行四辺形）
  であることが一目で分かります
- **板の中**: 遅相軸成分だけ位相が遅れ、出口で位相差 δ がつく
- **右下（手前）**: 2成分が合成されて **楕円偏光** に。受光板（スクリーン）上で電場ベクトルが回る

3Dビューは表示エリアの大きさに合わせて自動でシーン全体が収まるように調整されます
（ドラッグで視点を変えたあとは自動調整しません）。

姉妹アプリ [`../PoincareSphere`](../PoincareSphere/) が抽象的なポアンカレ球で偏光変換を
表すのに対し、本アプリは実空間で波の伝搬そのものを見せます。

## 起動方法

```bash
# 組み込みサーバーで起動（デフォルト: ポート3000）
node server.js

# ポート指定
PORT=8080 node server.js

# npm scripts
npm start
```

ブラウザで `http://localhost:3000/` を開いてください。
Three.js を CDN から読み込むため、**実行時にインターネット接続が必要**です。

## 操作方法

| 操作 | 説明 |
|------|------|
| **偏光板 角度 φ** | 入射直線偏光の向きを変える。**φ = 0° は遅相軸（縦）**が基準で、光の進む向きを後ろから見て**左回り（反時計回り）がプラス**。分解比 Ef:Es が変化 |
| **波長板 光路差 Γ**（λ/4・λ/2・λ ボタン / スライダー 0〜800nm） | 板が進相・遅相にどれだけ差をつけるかを **長さ(nm)** で指定。位相差は δ = 2π·Γ/λ として自動計算され、出力が 円 / 直線 / 楕円 に変わる |
| **再生 / 一時停止** | 波のアニメーションを止めてじっくり観察 |
| **コマ戻し / コマ送り** | 1/24 周期（位相 15°）ずつ手動で進める・戻す。再生中に押すと一時停止します |
| **速度** | アニメーション速度（0〜3倍） |
| **波長** | 光の波長（380〜750nm）。波の色が変わるのに加え、**Γ が同じでも δ が変わる**（λ/4 板が λ/4 でなくなる様子が見られる） |
| **ドラッグ** | 3Dビューを回転 |
| **ホイール** | ズーム |

## 見どころ（プリセット）

| 偏光板 φ | 波長板 Γ | 出てくる光 |
|---------|---------|-----------|
| 45° | λ/4 板（530nm なら 133nm） | **円偏光**（電場ベクトルが円を描いて回る） |
| 45° | λ/2 板（同 265nm） | **直線偏光**（向きが 90° 回転） |
| 45° | λ 板（同 530nm） | **直線偏光**（入射とまったく同じ） |
| 20° など | λ/4 板 | **楕円偏光**（つぶれた円） |
| 45° | λ/4 板にしてから**波長だけ**変える | 円偏光が崩れて **楕円偏光** に（板は同じでも δ が変わるため） |

> 表示は説明用にデフォルメしています（波長・板厚・旋光方向は実スケール・厳密規約ではありません）。
