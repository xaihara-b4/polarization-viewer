# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this directory.

## 概要

直線偏光が **偏光板 → 波長板（位相差板）→ 楕円偏光** と変化する様子を、実空間で
デフォルメして動的3D表示する教育用 Web アプリ。姉妹アプリ `../PoincareSphere/`（抽象的な
ストークス空間＝ポアンカレ球上の偏光変換）に対し、こちらは **実空間で波の伝搬**を描く。

## 起動方法

```bash
# 組み込みサーバーで起動（デフォルト: ポート3000）
node server.js

# ポート指定
PORT=8080 node server.js

# npm scripts
npm start
```

Three.js は CDN（importmap 経由）で読み込むため、**実行時にインターネット接続が必要**。
ビルド工程・npm 依存パッケージはなし。

## アーキテクチャ

- **`index.html`** — UI レイアウト。左に操作パネル、右に単一3Dビュー。importmap で Three.js を指定
- **`main.js`** — アプリ本体（ES Module、単一ファイル）
  - `rebuildStatic()`: φ / δ / λ 変更時に走る。透過軸バーの角度・波の色・スクリーンの楕円リング・
    状態テキストを更新
  - `updateWaves(t)`: 毎フレーム走る。全ラインの頂点座標を時刻 t で再計算（位置属性を in-place 更新）
  - `render()`: `requestAnimationFrame` ループ。再生中は t を進め、DPR/リサイズを処理して1ビューを描画
- **`server.js`** — Node.js 組み込み `http` モジュールのみの静的ファイルサーバ（`../PoincareSphere` と同一）
- **`README.md`** — ユーザー向けの使い方（UI 変更時は忘れず更新すること）

## 座標系・シーン規約

- 伝搬方向 = 世界の **+X**（左奥 → 右手前）。横断面 = **Y–Z**。カメラ上方向 = **+Z**
- 波長板の **進相軸(fast) = +Y（水平・固定）／遅相軸(slow) = +Z（垂直・固定）**
- レイアウト定数（`main.js` 冒頭）: `X_POL=-6`（偏光板）, `X_IN=-2`〜`X_OUT=2`（波長板）,
  `X_SCREEN=8`（スクリーン）。振幅 `A`、波長 `LAMBDA_W`、空間角周波数 `K=2π/LAMBDA_W`

## 物理仕様（デフォルメ）

- 偏光板の透過軸: `u = (0, cosφ, sinφ)`。φ は進相軸(+Y)からの角度
- 区間ごとに描き分ける（見やすさのため合成波と分岐波を重ねない）:
  - **`X_POL`〜`X_IN`（入射）**: 合成した直線偏光 `E = A cos(Kx − ωt) · u`（櫛付き, `incoming`）
  - **`X_IN`〜`X_OUT`（板内）**: 進相・遅相の**2成分のみ**（`fastComp` / `slowComp`）。合成波は描かない
  - **`X_OUT`〜`X_SCREEN`（通過後）**: 合成した**楕円偏光のみ**（`combined`）。分岐波は描かない。
    軸から波先端への櫛（`combOutLines`）を入射側（`combLines`）と同様に描き、直線→楕円の違いを対比
- 波長板での2成分:
  - 進相軸成分（Y, 速い）: 振幅 `Ef = A cosφ`、位相 `Kx − ωt`
  - 遅相軸成分（Z, 遅い）: 振幅 `Es = A sinφ`、位相 `Kx − ωt − δ·frac`
  - `frac = (x − X_IN)/(X_OUT − X_IN)`（板内で 0→1）… 遅相軸だけ位相が遅れ、**出口 `X_OUT` で相対位相差 = δ**
- 通過後の合成（実際の電場）: `E = (Ef cos(Kx−ωt)) ŷ + (Es cos(Kx−ωt−δ)) ẑ` → 楕円らせん（`frac=1` で δ 一定）
- **出口面（到達面, `X_OUT`）の伸縮矢印**: `X_OUT` での各成分を矢印で表示（`setArrow` で毎フレーム更新）
  - `arrowFast`（進相波, Y）／`arrowSlow`（遅相波, Z）／`arrowComb`（合成波, Y+Z）。長さ 0 付近は非表示
  - スクリーン(`X_SCREEN`)の `exitArrow` は「回る合成ベクトル」、こちらは出口面での「分解＋合成」を示す
- スクリーン上の楕円: ψ を 0..2π 掃引した `(Ef cosψ, Es cos(ψ−δ))`
- 回転の向き（`classifyOutput`）: `y z' − z y'` の符号 = `−Ef·Es·sinδ`。負を右回りと表示
  - **注**: 教育目的のデフォルメ表示であり、実機の旋光方向・絶対位相の厳密規約とは切り離している

## UI 操作項目

| 項目 | 範囲 | 既定 |
|------|------|------|
| 偏光板 透過軸角度 φ | 0–180°（スライダー） | 45° |
| 位相差 δ | λ/4=90° / λ/2=180° / λ=360°（プリセット）＋任意角スライダー 0–360° | 90° |
| アニメーション | 再生/一時停止・速度 0–3× ・波長 380–750nm | 再生, 1.0×, 530nm |

- 波の色は波長から自動決定（`wavelengthToColor`。`../PoincareSphere/main.js` と同じ変換）
- 既定 φ=45°, δ=λ/4 → 円偏光。δ=λ/2 → 直線が90°回転。δ=λ → 入射と同じ直線

## 特徴的な確認例

| φ | δ | 出力 |
|---|---|------|
| 45° | λ/4 (90°) | 円偏光 |
| 45° | λ/2 (180°) | 直線偏光（進相軸で反転＝90°回転） |
| 45° | λ (360°) | 直線偏光（入射と同じ） |
| 20° | λ/4 (90°) | 楕円偏光 |
