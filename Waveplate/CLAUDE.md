# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this directory.

## 概要

直線偏光が **偏光板 → 波長板（位相差板）→ 楕円偏光** と変化する様子を、実空間で
デフォルメして動的3D表示する教育用 Web アプリ。姉妹アプリ `../PoincareSphere/`（抽象的な
ストークス空間＝ポアンカレ球上の偏光変換）に対し、こちらは **実空間で波の伝搬**を描く。

## 起動方法

```bash
# 組み込みサーバーで起動（デフォルト: ポート3000）
node server.js

# ポート指定
PORT=8080 node server.js

# npm scripts
npm start
```

Three.js は CDN（importmap 経由）で読み込むため、**実行時にインターネット接続が必要**。
ビルド工程・npm 依存パッケージはなし。

## アーキテクチャ

- **`index.html`** — UI レイアウト。左に操作パネル、右に3Dビュー（`#gl` = WebGL、`#polar` = 左下の
  2D 極座標図）。importmap で Three.js を指定。
  パネル先頭の `.appnav` は姉妹アプリ（`../PoincareSphere/` / `../MOA/`）への切り替えリンク
  （公開サイト `_site/` 配下でのみ有効。単体で `server.js` を起動したときは 404 になる）
- **`main.js`** — アプリ本体（ES Module、単一ファイル）
  - `rebuildStatic()`: φ / δ / λ 変更時に走る。透過軸バーの角度・波の色・スクリーンの楕円リング・
    状態テキストを更新
  - `updateWaves(t)`: 毎フレーム走る。全ラインの頂点座標を時刻 t で再計算（位置属性を in-place 更新）
  - `frameScene()`: 初期表示とリサイズ時に走る。3D表示エリアの縦横比を見て、シーン全体
    （`FIT_STATIONS` の各断面の四隅）が画角に収まる注視点と距離を反復計算してカメラを置き直す。
    ユーザーが視点を操作したら（OrbitControls の `start` イベント）以降は自動フィットしない
  - `drawPolar()`: 3Dビュー左下の極座標図（Canvas 2D、`#polar`）を毎フレーム描く。Three.js とは
    独立した 2D 描画で、出口面 `X_OUT` を**受光側から見た真正面図**（右 = 進相軸 +Y / 上 = 遅相軸 +Z）。
    角度は上向き 0° から**時計回りが正**＝ φ の増える向きと一致。目盛りは主 10°・補助 5°・30° ごとに数値。
    `polarState.ref`（`'slow'` | `'trans'`）で 0° に合わせる軸を切り替え、図全体を `polarRefAngle()` 分回す。
    毎フレームの電場は `updateWaves()` が `exitFieldY` / `exitFieldZ` に置いた値を使う
  - `render()`: `requestAnimationFrame` ループ。再生中は t を進め、DPR/リサイズを処理して1ビューを描画
- **`server.js`** — Node.js 組み込み `http` モジュールのみの静的ファイルサーバ（`../PoincareSphere` と同一）
- **`README.md`** — ユーザー向けの使い方（UI 変更時は忘れず更新すること）

## 座標系・シーン規約

- 伝搬方向 = 世界の **+X**（左奥 → 右手前）。横断面 = **Y–Z**。カメラ上方向 = **+Z**
- 波長板の **進相軸(fast) = +Y（水平・固定）／遅相軸(slow) = +Z（垂直・固定）**
- レイアウト定数（`main.js` 冒頭）: `X_POL=-6`（偏光板）, `X_IN=-2`〜`X_OUT=2`（波長板）,
  `X_SCREEN=8`（受光板／スクリーン、半サイズ `SCREEN_R`）。振幅 `A`、波長 `LAMBDA_W`、
  空間角周波数 `K=2π/LAMBDA_W`
- 初期視点は `VIEW_DIR`（注視点→カメラの単位ベクトル）で決める。**偏光板が画面の左上（奥）、
  受光板が右下（手前）** に来る斜め構図。大きさは `frameScene()` が表示エリアに合わせて自動調整

## 物理仕様（デフォルメ）

- 偏光板の透過軸: `u = (0, sinφ, cosφ)`（`transAxis()`）。**φ = 0° は遅相軸(+Z, 縦)**が基準で、
  φ を増やすと +Z → +Y へ回る。これは**伝搬方向 +X を後ろから見て左回り（反時計回り）が正**という向き
  （画面の既定視点は受光側から見ているので、見た目は時計回りに倒れる）。
  透過軸バーは `axisBar.rotation.x = π/2 − φ`、ラベル `透過軸` はバーの子スプライトで一緒に回る
- 区間ごとに描き分ける（見やすさのため合成波と分岐波を重ねない）:
  - **`X_POL`〜`X_IN`（入射）**: 合成した直線偏光 `E = A cos(Kx − ωt) · u`（櫛付き, `incoming`）
  - **`X_IN`〜`X_OUT`（板内）**: 進相・遅相の**2成分のみ**（`fastComp` / `slowComp`）。合成波は描かない
  - **`X_OUT`〜`X_SCREEN`（通過後）**: 合成した**楕円偏光のみ**（`combined`）。分岐波は描かない。
    軸から波先端への櫛（`combOutLines`）を入射側（`combLines`）と同様に描き、直線→楕円の違いを対比
- **位相差 δ は UI から直接与えず、光路差（リタデーション）`stateP.retard` [nm] から導出**する:
  `δ = 2π·Γ/λ`（`rebuildStatic()` の先頭で計算）。Γ は板の厚みで決まる固有値という扱いなので、
  波長 λ を変えると δ が変わる（λ/4 板が λ/4 なのは設計波長のときだけ）。δ は 2π を超えうるが、
  出力の偏光状態を決めるのは `δ mod 2π`（表示は `δ = 720°（≡ 0°）` のように併記）
- 波長板での2成分:
  - 進相軸成分（Y, 速い）: 振幅 `Ef = A sinφ`、位相 `Kx − ωt`
  - 遅相軸成分（Z, 遅い）: 振幅 `Es = A cosφ`、位相 `Kx − ωt − δ·frac`
  - `frac = (x − X_IN)/(X_OUT − X_IN)`（板内で 0→1）… 遅相軸だけ位相が遅れ、**出口 `X_OUT` で相対位相差 = δ**
- 通過後の合成（実際の電場）: `E = (Ef cos(Kx−ωt)) ŷ + (Es cos(Kx−ωt−δ)) ẑ` → 楕円らせん（`frac=1` で δ 一定）
- **入口面 `X_IN` / 出口面 `X_OUT` の伸縮矢印**: その面での各成分を矢印で表示（`setArrow` で毎フレーム更新）
  - 入口: `arrowFastIn` / `arrowSlowIn` / `arrowCombIn`。`frac=0` なので**2成分は同位相**で伸縮し、
    合成は入射の直線偏光（透過軸の向きに伸び縮みするだけ）
  - 出口: `arrowFast` / `arrowSlow` / `arrowComb`。遅相軸が δ だけ遅れ、合成は楕円を描く
  - 出口面には**平行四辺形の残り2辺**を破線で描く（`combGuide`、`LineDashedMaterial` + 頂点カラー）:
    進相の先端→合成の先端は遅相ベクトルの平行移動なので遅相色、その逆は進相色。
    位置更新のたびに `computeLineDistances()` で破線の刻みを再計算する
  - 入口面の `進相軸/遅相軸` は薄い軸ガイド線（`addAxisGuide`）で示す。長さ 0 付近の矢印は非表示
  - スクリーン(`X_SCREEN`)の `exitArrow` は「回る合成ベクトル」、両面の矢印は「分解＋合成」を示す
- スクリーン上の楕円: ψ を 0..2π 掃引した `(Ef cosψ, Es cos(ψ−δ))`（`ellipse`）
  - **波長板出口 `X_OUT` にも同じ楕円**を描く（`exitEllipse`）。出口以降は Ef, Es, δ が変わらないので
    受光板と同じ形になる。UI のチェックボックスで `visible` を切り替える（頂点座標は常に更新）
- 円偏光の判定（`classifyOutput`）: δ ≈ ±90° かつ `|Ef| ≈ |Es|`（φ=45° と 135° の両方で成立）
- 回転の向き（`classifyOutput`）: `y z' − z y'` の符号 = `−Ef·Es·sinδ`。負を右回りと表示。
  これは**受光側から光源を見た向き**（偏光の右回り/左回りの慣用）で、φ の正方向の定義
  （光源の後ろから見て左回り）とは視点が逆なので注意
  - **注**: 教育目的のデフォルメ表示であり、実機の旋光方向・絶対位相の厳密規約とは切り離している

## UI 操作項目

| 項目 | 範囲 | 既定 |
|------|------|------|
| 偏光板 透過軸角度 φ | 0–180°（スライダー）。0° = 遅相軸(縦)、正回転 = 進行方向を後ろから見て左回り | 45° |
| 波長板 光路差 Γ | 0–800 nm（スライダー）＋プリセット λ/4・λ/2・λ 板 | 133 nm |
| 表示 | 波長板出口の合成波の軌跡（楕円）ON/OFF・出口面の極座標図 ON/OFF・極座標図の 0° 基準（遅相軸／透過軸） | ON, ON, 遅相軸 |
| アニメーション | 再生/一時停止・コマ送り/コマ戻し・速度 0–3× ・波長 380–750nm | 再生, 1.0×, 530nm |

- コマ送り（`stepTime()`）は時刻 `t` を `STEP_T = (2π/OMEGA)/24`（1/24 周期 = 位相 15°）ずつ
  進める／戻すだけ。描画は `render()` が毎フレーム `updateWaves(t)` するので任せる。
  再生中に押した場合は自動で一時停止に切り替える

- Γ の UI は **nm 単位**。プリセットは「現在の波長を設計波長として Γ = frac·λ」を入れる
  （`applyRetard()` が Γ→δ 換算・表示・プリセットのアクティブ判定をまとめて行う）
- 波の色は波長から自動決定（`wavelengthToColor`。`../PoincareSphere/main.js` と同じ変換）
- 既定 φ=45°, Γ=133nm@530nm（≒λ/4, δ=90°）→ 円偏光

## 特徴的な確認例

| φ | Γ（λ=530nm のとき） | δ | 出力 |
|---|---|---|------|
| 45° | λ/4 ≈ 133 nm | 90° | 円偏光 |
| 45° | λ/2 ≈ 265 nm | 180° | 直線偏光（進相軸で反転＝90°回転） |
| 45° | λ ≈ 530 nm | 360° | 直線偏光（入射と同じ） |
| 20° | λ/4 ≈ 133 nm | 90° | 楕円偏光 |
| 45° | 133 nm のまま λ を 650nm へ | 74° | 楕円偏光（板は同じでも波長で変わる） |
