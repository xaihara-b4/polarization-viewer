# 平行ニコル 3波長で次数を決める

平行ニコル（偏光子と検光子の透過軸が平行）で複屈折試料のリタデーション R を測ると、
得られるのは

```
c = cos(2πR/λ)        平行ニコルの透過率 T∥ = (1 + c)/2
```

という **c ひとつだけ**です。ここから R を逆算しようとすると、位相 δ = 2πR/λ が
**何周したか（＝次数 m）がわからない**ため、R が一つに決まりません。

このアプリは

1. **単波長では次数が決まらない**こと
2. **590 / 610 / 630 nm の 3 波長で測ると次数が確定する**仕組み

を、候補が絞られていく過程として見せる教育用 Web アプリです。

> **前提**: 波長分散は無いものとしています（R は波長によらず一定）。
> これがあるので「3 つの波長が同じ R を指す」という一致条件が使えます。

## 起動

```bash
node server.js          # http://localhost:3000
PORT=8080 node server.js
npm start
```

外部ライブラリを使っていないので、**オフラインでも動きます**。

## 画面

| 位置 | 内容 |
|------|------|
| ① 最上段 | **極座標グラフ（波長ごとに 1 枚）**。試料を回したときの透過率。**45° の値が c** |
| ② | 各波長の **c–R 曲線**と測定値の水平線。交点がその波長の候補 R |
| ③ | **候補コム**。共通の R 軸に 3 段の櫛を並べ、**3 段すべてがそろう R** をシアンで示す |
| ④ | **一致度 D(R) = max\|Δc\|**。許容幅の線より下が「生き残る」領域。谷が深いほど誤差に強い |
| 左パネル | **位相円**。δ = 2πR/λ が単位円を何周したかが次数 m。横軸への射影が c |

色は 3 つのグラフで共通です。

- **黄 = 590 nm / 橙 = 610 nm / 赤桃 = 630 nm**
  （実際の色ではどれも橙〜赤で見分けられないため、順序感を保ちつつ分離した 3 色にしています）
- **シアン** = 測定から決まった候補、**水色（破線）** = 真の R（答え合わせ用）

## ① 極座標グラフの読み方

試料の方位角 θ を回すと、透過率は

```
平行ニコル  T∥(θ) = 1 − sin²2θ · sin²(δ/2)
直交ニコル  T⊥(θ) = sin²2θ · sin²(δ/2)          sin²(δ/2) = (1 − c)/2
```

と 90° 周期で変化します。**形を決めているのは c だけ**です。

- **θ = 0° / 90°**（試料の軸が偏光子と平行 or 直交）… 複屈折が効かず平行ニコルでは T = 1
- **θ = 45°** … 最も深くくびれ、その値が **T∥ = (1 + c)/2**。**ここが測定点**です

R = 1400 nm では 3 波長の 45° の値が

| λ | c | T∥(45°) | 見え方 |
|---|---|---------|--------|
| 590 nm | −0.698 | 0.151 | 深くくびれた四つ葉 |
| 610 nm | −0.279 | 0.360 | 中くらい |
| 630 nm | +0.174 | 0.587 | ほぼ円に近い |

と**はっきり違う形**になります。この 3 つの違いが次数を決める手がかりです。

> 3 波長を 1 枚に重ねると形の違いが読めなくなるため、**必ず波長ごとに別のグラフ**にしています。

## 使い方

**入力するのは「真の R」**です。アプリはそこから各波長の c を作り、
以降は「**c しか見えない測定者**」の立場で R を逆算して並べます。
真値がその候補列の 1 本にすぎないことを見せるのが狙いです。

### 試してほしい手順（既定 R = 1400 nm）

1. **590 nm だけ ON にする** → 候補が 10 本出ます。これが単波長の限界です

   ```
   220, 370, 810, 960, 1400, 1550, 1990, 2140, 2580, 2730 nm
   ```

2. **610 nm も ON にする** → 候補が 1400 nm の 1 本に絞れます
3. **許容幅を 0.10 に上げる** → 2 波長では **799 / 1400 / 2002 nm** の 3 本に戻ってしまいます
4. **630 nm も ON にする** → 3 波長なら 0.10 でも、0.15 でも **1400 nm の 1 本のまま**

これが「3 波長で測る」ことの意味です。

## なぜ 3 波長なのか

3 波長の候補列が完全に一致し直すのは最小公倍数 **LCM(590, 610, 630) = 2,267,370 nm ≈ 2.3 mm**
先なので、実用レンジでは原理的には 2 波長でも一意に決まります。
**実際の限界を決めるのは測定誤差のほう**です。

R = 1400 nm のとき、真値以外で最も浅い谷の深さは

| 使用波長 | 偽の谷の深さ D |
|----------|---------------|
| 590 + 610 | 0.084（R ≈ 2002 nm） |
| 590 + 610 + 630 | **0.157**（R ≈ 2014 nm） |

3 本目が**許容できる測定誤差を約 2 倍に広げます**。これがグラフ ③ の
「谷が深いほど誤差に強い」という意味です。

## 苦手な条件

- **c ≈ ±1 の近く**（明点・暗点の近傍）は cos の頂点なので、R が動いても c がほとんど変わらず分離が悪くなります
- **R ≈ 0 は常に対抗馬**です。R = 0 では全波長で c = 1 になるため、測定値が c ≈ 1 のときは区別しにくくなります
- 例: **R = 610 nm** にすると、3 波長・許容幅 0.02 まで絞っても R ≈ 14.4 nm が候補として残ります

## 操作項目

| 項目 | 範囲 | 既定 |
|------|------|------|
| 真のリタデーション R | 0–3000 nm | 1400 nm |
| 使用波長 | 590 / 610 / 630 nm の ON/OFF | すべて ON |
| 測定誤差の許容幅 | 0.005–0.15（c の絶対誤差） | ±0.050 |
| 位相円に出す波長 | 590 / 610 / 630 | 590 |
| ニコル配置 | 平行 / 直交 | 平行 |
| 縦軸 | c / 透過率 T | c |
| 候補コムの次数 m 表示 | ON/OFF | ON |
| R の掃引 | 再生/一時停止・速度 0–3×（1× で 300 nm/秒） | 停止, 1.0× |
