平行ニコル 3波長で次数を決める

平行ニコルで測れるのは c = cos(2πR/λ) だけ。
1 波長では次数 m が決まらず R が定まりません。
590 / 610 / 630 nm の 3 波長で測ると、
3 つの候補列がそろう R が 1 つに決まります。
試料（測定対象）
R [nm]（測定者には見えない値）
アプリはこの R から各波長の c を作ります。以下の表示は 「c しか見えない測定者」が R を逆算した結果です。
測定に使う波長
1 本 → 2 本 → 3 本と増やすと候補が絞られます。
波長分散は無いものとする（R は波長によらず一定）。
±0.050
全波長で |Δc| ≤ 許容幅 なら候補として残す判定。
2 波長だと 0.10 で偽の候補が復活しますが、
3 波長なら 0.15 でも 1 本のままです。
位相円（次数 = 巻き数）
δ = 2πR/λ が単位円を何周したかが次数 m。
測定できるのは横軸への射影 c だけなので、
巻き数の情報が落ちてしまいます。

読み方: ①の極座標は試料を回したときの
透過率 T∥(θ) = 1 − sin²2θ·sin²(δ/2)。
0°/90° では複屈折が効かず T = 1、
45° でくびれ、その深さが c を表します。
②で c 曲線と測定値の水平線が交わる R が候補。
③の候補コムで 3 段そろう位置が答え。
④の一致度 D(R) が許容幅の線を下回る谷が

限界: c ≈ ±1 付近（明点・暗点の近く）は
cos の頂点で感度が落ちます。R = 610 で確認を。
① 実際の測定 ― 試料を回したときの透過率（極座標・0° = 偏光子軸、左回りが正）。 45° の値がそのまま c を与えます。3 波長で形が違うことが次数決定の手がかり。
② 各波長の c–R 曲線と測定値の水平線 ／ 交点 = その波長の候補 R（水色 = 真の R）
③ 候補コム ― 3 段すべてがそろう R が答え（シアン = 生き残った候補）
