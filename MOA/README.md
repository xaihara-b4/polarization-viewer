# 分子配向計 3D ↔ 配向パターン

マイクロ波分子配向計（MOA）の測定で出てくる 2 つのグラフ

- **左の 3D グラフ** … 試料 1 回転中の共振曲線の変化（周波数 f × 回転角 θ × 透過マイクロ波強度）
- **右上のグラフ** … 配向パターン（周波数 f<sub>m</sub> 固定で試料を 1 回転させたときの強度変化）

の **関係** を体感するための教育用 Web アプリです。
「3D の面を f = f<sub>m</sub> で切った断面を、極座標に巻き取ったものが配向パターン」
という対応を、断面プレーン・交線・巻き取りアニメーションで見せます。

## 起動

```bash
node server.js          # http://localhost:3000
PORT=8080 node server.js
npm start
```

Three.js を CDN から読み込むため、実行時にインターネット接続が必要です。

## 画面

| 位置 | 内容 |
|------|------|
| 左（3D） | 共振曲線群（f × θ）。水色の板が f = f<sub>m</sub> の断面、**シアン**の線がその交線、**黄**が現在の θ の共振曲線 |
| 右上 | 配向パターン（極座標。**0° が上・左回り（反時計回り）が正**）。破線 = 長軸（強度最大の向き）、実線 = 配向角（長軸 + 90°）、MOR = max/min |
| 右下 | 現在の θ の共振曲線と f<sub>m</sub>。水色の破線が f<sub>m</sub> を決める共振曲線（fr 最大の θ）とその半値、**シアン**の点が「いま測っている 1 点」 |

3 つのグラフで色を共通にしてあり、**シアンの点・白い球・黄色の点**が同じ 1 つの測定点を指します。
再生すると試料が回転し、その 1 点が配向パターンを 1 周ぶん描いていきます。

## 使い方

1. **▶ 断面を極座標へ巻き取る** … 視点が f 軸の正面へ移動し、3D の断面カーブが
   そのまま極座標へ変形します。右上のグラフと同じ形・同じ向きになります
   （スライダーで途中の状態も見られます）
2. **配向角 φ₀ / 誘電率異方性 Δε′ / Q 値** … 試料と共振器の条件。
   f<sub>m</sub> はこれらから自動で決まり直します（下記のとおり）

## 物理モデル（デフォルメ）

- 電界方向の誘電率: ε′(θ) = ε′<sub>ave</sub> + (Δε′/2)·cos 2(θ − φ₀)（配向方向 θ = φ₀ で最大）
- 摂動法: 試料を入れると共振周波数が下がる。ε′ が大きいほど下がる
  → f<sub>r</sub>(θ) = f<sub>r0</sub> − K·(ε′(θ) − ε′<sub>ave</sub>)
- 共振曲線: ローレンツ型 I(f) = 1 / (1 + x²), x = (f − f<sub>r</sub>)/(f<sub>r</sub>/2Q)
- **測定周波数 f<sub>m</sub>（自動決定）**: 1 回転中で共振周波数が最も高くなる θ
  （= φ₀ + 90°、ε′ が最小の向き）のピークを選び、その**高周波側の半値**の位置を f<sub>m</sub> とする。
  ローレンツ型では半値は f<sub>r</sub> ± 半値半幅なので
  **f<sub>m</sub> = f<sub>r,max</sub> + f<sub>r,max</sub>/(2Q)**
- 配向パターン: I(f<sub>m</sub>, θ) を θ について極座標プロット。MOR = I<sub>max</sub>/I<sub>min</sub>

f<sub>m</sub> は必ず全ピークより高周波側にあるので、**ε′ が小さい向き（＝ 配向と直交する向き）ほど
共振周波数が f<sub>m</sub> に近づいて強度が大きく**なります。したがってパターンの長軸は配向方向と直交し、
**配向角 = 長軸 + 90°** として表示しています（既定値では ANGLE = 30.0° = 入力した φ₀）。

また f<sub>m</sub> がピークをまたがないため、パターンは常に素直な 2 山（180° 周期）になります。

Q 値の変化（誘電損失 ε″）による強度低下は扱っていません。ε′ の異方性だけのモデルです。
