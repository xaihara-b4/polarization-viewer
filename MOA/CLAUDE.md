# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this directory.

## 概要

マイクロ波分子配向計（MOA）の測定資料にある **「試料1回転中の共振曲線の変化（3D）」** と
**「配向パターン（極座標）」** の関係を説明する教育用 Web アプリ。
3D 面を f = fm で切った断面 I(θ) を極座標へ**巻き取る**アニメーションで両者を結びつける。

姉妹アプリ `../PoincareSphere/`（ストークス空間）、`../Waveplate/`（実空間の波の伝搬）と
同じ作り（Three.js を CDN 読み込み・ビルド工程なし・ダークテーマ）。

## 起動方法

```bash
node server.js          # デフォルト http://localhost:3000
PORT=8080 node server.js
npm start
```

Three.js は importmap 経由の CDN 読み込みなので**実行時にインターネット接続が必要**。

## アーキテクチャ

- **`index.html`** — 左に操作パネル、右に表示エリア（`#view3d` = WebGL、`#polar` = 配向パターン、
  `#curve` = 共振曲線の 2D Canvas）。importmap で Three.js を指定。
  パネル先頭の `.appnav` は姉妹アプリ（`../Waveplate/` / `../PoincareSphere/`）への切り替えリンク
  （公開サイト `_site/` 配下でのみ有効。単体で `server.js` を起動したときは 404 になる）
- **`main.js`** — アプリ本体（ES Module、単一ファイル）
  - `refresh()`: パラメータ変更時に走る一括更新（`recomputeCut` → `rebuildSurface` →
    `updateCut` → `updateCurrent` → `updateFade` → `updateStatus`）
  - `recomputeCut()`: f = fm 断面の I(θ) を `cutI` に計算し、`cutStat`（max/min/thetaMax/mor/angle）を更新
  - `rebuildSurface()`: 共振曲線 37 本（`curveLines`）と陰線処理用の面（`surface`）の頂点を再計算
  - `updateCut()`: 断面カーブを **直交（3D の交線）↔ 極座標（配向パターン）** の間で
    `st.morph`（0..1）により線形補間する。巻き取りの本体。断面プレーン・極座標グリッドの
    位置と不透明度もここで更新
  - `updateCurrent()`: 現在の θ の共振曲線とマーカー（3 グラフ共通の測定点）を毎フレーム更新
  - `drawPolar()` / `drawCurvePanel()`: 右側 2 つの 2D パネルを毎フレーム描画（Canvas 2D）
  - `setView()`: 「斜め視点 / 正面（f 軸から）」のカメラ移動。`fly` に補間状態を持ち `render()` で進める
  - `render()`: `requestAnimationFrame` ループ。θ の自動回転・巻き取り補間・カメラ移動・DPR/リサイズ処理
- **`server.js`** — Node.js 組み込み `http` のみの静的サーバ（他アプリと同一）
- **`README.md`** — ユーザー向けの使い方（UI 変更時は忘れず更新すること）

## 座標系・表示規約

- 3D: **x = 周波数 f**（`xOfF`）、**z = 回転角 θ**（`zOfTheta`、θ=0 が手前 +Z）、**y = 透過マイクロ波強度**（`yOfI`）
- 巻き取り先の極座標は **f = fm 断面プレーン内**（x 固定、y–z 平面）。
  **0° = +y（上）、時計回りが正**＝ 右上の 2D パネルと同じ向き。
  正面視点（カメラを +x 側に置く）では画面右が −z になるため
  `(y, z) = (cy + r·cosθ, cz − r·sinθ)` で 2D パネルと一致する
- 色の対応（3 つのグラフを結ぶ手がかり）:
  シアン `#36d1c4` = f = fm の断面／配向パターン、黄 `#ffd166` = 現在の θ、
  水色 `#8ecbff` = 測定周波数 fm、白い球 = 現在の測定点

## 物理仕様（デフォルメ）

- ε′(θ) = `EPS_AVE` + (Δε′/2)·cos 2(θ − φ₀) … 配向方向 θ = φ₀ で最大（`epsAt`）
- 摂動法により ε′ が大きいほど共振周波数が下がる: fr(θ) = `FR0` − `KF`·(ε′(θ) − `EPS_AVE`)（`frAt`）
- 共振曲線はローレンツ型 I = 1/(1+x²), x = (f − fr)/(fr/2Q)（`intensityAt`）。ピーク高さは一定
  （誘電損失 ε″ による Q 低下・強度低下は扱わない）
- **測定周波数 fm は UI から与えず自動決定**（`computeFm`、実機の設定手順に合わせた仕様）:
  1 回転中で共振周波数が最も高くなる θ（= φ₀ + 90°、ε′ 最小の向き。`frMaxAngle`）の
  ピークの**高周波側の半値**＝ `fm = frMax + frMax/(2Q)`。
  `refresh()` の先頭で `st.fm` に入れ直すので、φ₀ / Δε′ / Q を動かすと fm も追従する
- 配向パターン = I(fm, θ) の極座標プロット。**fm は常に全ピークより高周波側**にあるため
  I(θ) は fr について単調 → パターンは必ず 2 山（180° 周期）で、最大は ε′ 最小の向きに出る。
  よって `cutStat.longAxis`（強度最大の向き）は配向方向と直交し、
  **`cutStat.angle` = 長軸 + 90° を「配向角 (ANGLE)」として表示**する（`foldAxisAngle` で (−90°, 90°] に畳む）。
  MOR = Imax/Imin
- `KF = 3.0` は既定 Δε′ = 0.30・Q = 2000 のとき MOR ≈ 2.3 になる程度のスケール
  （資料の GFRP 例は MOR = 2.025）

## UI 操作項目

| 項目 | 範囲 | 既定 |
|------|------|------|
| 配向角 φ₀ | 0–180° | 30° |
| 誘電率異方性 Δε′ | 0–1.0 | 0.30 |
| Q 値 | 800–6000 | 2000 |
| 測定周波数 fm | 操作不可（`computeFm()` が自動決定。値のみ表示） | 4001.45 MHz |
| 巻き取り | ボタン（正面視点へ移動も同時）＋ 0–100% スライダー | 0% |
| 表示 | 断面プレーン・交線・面の塗り（陰線処理） | すべて ON |
| 試料の回転 | 再生/一時停止・10°送り・θ 0–360°・速度 0–3×（1× で 12 秒/回転） | 再生, 1.0× |

## 特徴的な確認例

既定（φ₀ = 30°, Δε′ = 0.30, Q = 2000）で fm = 4001.45 MHz, 長軸 = −60.0°, ANGLE = 30.0°, MOR = 2.306。
ANGLE は入力した φ₀ を復元する（長軸は常に φ₀ と直交する）。

| 操作 | 結果 |
|------|------|
| Δε′ = 0.10 | fm = 4001.15、MOR = 1.345（異方性が小さいとパターンが丸くなる） |
| Δε′ = 1.00 | fm = 4002.50、MOR = 8.508 |
| Q = 6000 | 共振曲線が鋭くなり fm = 4000.78 まで下がる、MOR = 7.347 |
| Q = 800 | 共振曲線が広がり fm = 4002.95、MOR = 1.425 |
| φ₀ = 120° | 長軸 = 30.0° → ANGLE = −60.0°（(−90°, 90°] に畳んだ値） |
