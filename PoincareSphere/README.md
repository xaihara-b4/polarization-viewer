# ポアンカレ球ビューア 使い方

偏光状態（ストークスパラメータ）と位相差板の条件を入力すると、ポアンカレ球上に
入力偏光・位相差板通過後の出力偏光・回転軌跡を 3D 表示する Web アプリです。
複数の測定条件（波長・リタデーション）を並べて入力し、波長分散による出力の違いを
1 つの球上で色分けして比較できます。

## 起動方法

Node.js がインストールされていれば、追加のパッケージは不要です。

```bash
cd PoincareSphere
node server.js          # デフォルト: http://localhost:3000
```

ポートを変えたい場合:

```bash
PORT=8080 node server.js
```

起動したらブラウザで表示された URL を開いてください。

> **注意**: 3D 描画ライブラリ（Three.js）を CDN から読み込むため、
> **実行時にインターネット接続が必要**です。

## 画面構成

| 領域 | 内容 |
|------|------|
| 左パネル | 入力欄と計算結果 |
| 右上（大） | メイン 3D ビュー。**ドラッグで自由回転、ホイールでズーム** |
| 右下・左 | 平面図（北極側から見下ろした図。右が +S1、上が +S2） |
| 右下・中 | 側面図（+S1 方向から見た図。上が +S3） |
| 右下・右 | 側面図（+S2 方向から見た図。上が +S3） |

平面図・側面図では、視線方向（画面中心）に重なる軸ラベルの文字は表示しません。

## 入力項目

### ストークスパラメータ S1, S2, S3

入力偏光の状態を指定します。3 値は自動的に長さ 1 に正規化され、球面上の点（青）として表示されます（完全偏光を仮定）。

代表的な偏光状態:

| 偏光状態 | (S1, S2, S3) |
|----------|--------------|
| 水平直線偏光 | (1, 0, 0) |
| 垂直直線偏光 | (−1, 0, 0) |
| +45° 直線偏光 | (0, 1, 0) |
| −45° 直線偏光 | (0, −1, 0) |
| 右円偏光（北極） | (0, 0, 1) |
| 左円偏光（南極） | (0, 0, −1) |

### 進相軸角度 θ（度）

位相差板の進相軸の方位角です。水平（S1 方向）から反時計回りに測ります。
**すべての測定条件行に共通**で適用されます。

### 測定条件（波長 λ・リタデーション R）

1 行が 1 つの測定条件で、それぞれ波長 λ [nm] とリタデーション R [nm] を入力します。

- **「＋ 条件を追加」** — 行を追加します（最後の行の値を初期値としてコピー）
- **「×」** — その行を削除します
- 行頭の**色マーカー**が、球面上の出力点・軌跡の色に対応します。
  色は波長から自動的に決まります（450 nm → 青、530 nm → 緑、633 nm → 赤、
  可視域 380〜780 nm の外はグレー）

位相差 δ は行ごとに次式で自動計算されます:

```
δ = 360° × R / λ
```

例: R = 132.5 nm, λ = 530 nm → δ = 90°（λ/4 板に相当）

## 表示の見方

- **白い点** — 入力偏光（正規化後）
- **色付きの点・円弧** — 各測定条件の出力偏光と、そこに至る回転軌跡（波長に応じた色）
- **紫の破線** — 位相差板による回転軸。赤道面上の (cos 2θ, sin 2θ, 0) 方向
- **北極（S3 = +1）** — 右円偏光、**南極（S3 = −1）** — 左円偏光

位相差板の作用はポアンカレ球上では「回転軸まわりの δ 回転」なので、
入力点から各出力点へ向かう円弧の長さの違いが、そのまま波長による位相差の違いを表します。

左パネル下部には、正規化後の入力 S・回転軸・行ごとの δ と出力 S が色付きで一覧表示されます。

## 使用例: λ/4 板の波長分散を見る

1. S1 = 1, S2 = 0, S3 = 0（水平直線偏光）を入力
2. 進相軸角度 θ = 45° を入力
3. 測定条件に (λ=450, R=132.5), (λ=530, R=132.5), (λ=633, R=132.5) の 3 行を設定（デフォルト値）

530 nm では δ = 90° でちょうど右円偏光（北極）になりますが、
450 nm では回りすぎ（δ = 106°）、633 nm では足りず（δ = 75.4°）、
出力点が北極からずれる様子が確認できます。

## トラブルシューティング

| 症状 | 対処 |
|------|------|
| 球が表示されない | インターネット接続を確認（Three.js を CDN から読み込むため） |
| 「S1, S2, S3 がすべて 0 です」 | 少なくとも 1 つに 0 以外の値を入力 |
| 「λ・R が不正です」 | その行の波長が正の数値か、R が数値かを確認 |
| ポート使用中エラー | `PORT=8080 node server.js` のように別ポートを指定 |
