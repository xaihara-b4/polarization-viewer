# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this directory.

## 概要

偏光状態（ストークスパラメータ S1, S2, S3）・位相差板の進相軸角度・複数の測定条件（波長 λ とリタデーション R のペア）を入力し、
ポアンカレ球上に入力偏光と、条件ごとに色分けした出力偏光・回転軌跡を 3D 表示する Web アプリ。
波長分散による出力偏光の違いなどを 1 つの球上で比較できる。

## 起動方法

```bash
# 組み込みサーバーで起動（デフォルト: ポート3000）
node server.js

# ポート指定
PORT=8080 node server.js

# npm scripts
npm start

# 外部ツールで起動
npx http-server . -p 8080
```

Three.js は CDN（importmap 経由）で読み込むため、**実行時にインターネット接続が必要**。
ビルド工程・npm 依存パッケージはなし。

## アーキテクチャ

- **`index.html`** — UI レイアウト。左に入力パネル、右に 4 ビューのグリッド。importmap で Three.js を指定
- **`main.js`** — アプリ本体（ES Module、単一ファイル）
  - ストークスベクトルの正規化・位相差板の回転計算（Rodrigues の回転公式）
  - Three.js シーン（球・軸・点・軌跡）は 1 つを共有し、**ビューごとに独立した canvas +
    WebGLRenderer** で描画する。1 canvas のシザー分割はビュー矩形の座標計算が
    ウィンドウリサイズ・ズーム等の環境差でずれやすいため使わないこと
  - 入力変更イベントで即時再計算・再描画
- **`server.js`** — Node.js 組み込み `http` モジュールのみの静的ファイルサーバ
- **`README.md`** — ユーザー向けの使い方ドキュメント（UI の変更時は忘れず更新すること）

## ビュー構成

| ビュー | カメラ | 説明 |
|--------|--------|------|
| メイン 3D | 透視投影 + OrbitControls | マウスドラッグで自由回転、ホイールでズーム |
| 平面図 | 正投影、北極側（S3+）から −S3 方向を見る | 上方向 = +S2、右 = +S1 |
| 側面図 1 | 正投影、+S1 方向から原点を見る | 上方向 = +S3 |
| 側面図 2 | 正投影、+S2 方向から原点を見る | 上方向 = +S3 |

正投影ビューでは、視線方向（画面中心）に重なる軸・極のラベル文字を表示しない。
ラベルスプライトを `THREE.Layers`（`LAYER_S1` 〜 `LAYER_LCP`）に振り分け、
`makeOrthoCamera` の `labelLayers` 引数で表示するラベルをビューごとに指定する。

## 物理仕様（規約）

- 座標系: three.js の (x, y, z) = (S1, S2, S3)、上方向は +S3（`camera.up = (0,0,1)`）
- 入力 (S1, S2, S3) は**自動正規化**して単位球面上に表示（完全偏光を仮定）。ゼロベクトルはエラー表示
- 位相差板はリタデーション R [nm] と測定波長 λ [nm] から位相差を計算: **δ = 360° × R / λ**
  （例: R = 132.5 nm, λ = 530 nm → δ = 90° = λ/4 板）
- 位相差板（進相軸角度 θ、水平 = S1 方向から反時計回りに測る）の作用は、
  ストークス空間で軸 **a = (cos 2θ, sin 2θ, 0)** まわりの **−δ 回転**（右手系）
  - 採用した Mueller 行列規約（θ = 0 のとき）: S2' = S2 cos δ + S3 sin δ、S3' = −S2 sin δ + S3 cos δ
  - 検証例: 入力 +45° 直線偏光 (0, 1, 0) を θ = 0° の λ/4 板に通すと (0, 0, −1)（南極 = 左円偏光）
- 北極 S3 = +1 は右円偏光（RCP）、南極 S3 = −1 は左円偏光（LCP）
- 軌跡は入力点から回転角 0 → −δ をサンプリングした球面上の円弧として描画。
  条件行ごとに描画半径をわずかにずらして（+0.004 刻み）重なりを回避

## UI 入力項目

| 項目 | 単位 | デフォルト |
|------|------|-----------|
| S1, S2, S3 | 無次元（自動正規化） | (1, 0, 0) |
| 位相差板 進相軸角度 θ（全条件共通） | 度 | 45 |
| 測定条件行: 波長 λ・リタデーション R | nm | (450, 132.5), (530, 132.5), (633, 132.5) の3行 |

- 測定条件（λ, R）の行は「＋ 条件を追加」/「×」ボタンで追加・削除できる（`main.js` の `conds` 配列で管理）
- 入力偏光 S と進相軸角度 θ は全条件で共通。条件行ごとに δ を計算し、出力点・軌跡を色分け表示する
- 条件行の色は波長から自動決定（`wavelengthToColor`: 可視光の近似色。450nm→青、530nm→緑、
  633nm→赤。可視域外 380〜780nm 以外はグレー）。入力点は白（`IN_COLOR`）
- 計算結果（正規化後の入力 S、回転軸、行ごとの δ と出力 S）は入力パネル下部に色付きで一覧表示する
